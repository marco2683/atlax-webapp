# Layer 1: Directive (What to do)

This directory contains Standard Operating Procedures (SOPs) written in Markdown.

## Principles
- Define the goals, inputs, tools/scripts to use, outputs, and edge cases.
- Write natural language instructions, like you'd give a mid-level employee.
- Directives are living documents. Update them with learnings (API constraints, better approaches, common errors).

## Organization
- Each major process should have its own `.md` file.
- Example: `scrape_website.md`
